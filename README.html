Start in less than a minute

  1. Extract the entire ZIP to a folder. Open index.html in a current Microsoft Edge or Google Chrome browser. On Windows, you can also double-click OPEN-DEMO.cmd.
  2. Explore Overview, then click a summary card to see the matching recce jobs.
  3. Choose Recce view in the top bar, open My recce and start an assigned job.
  4. Enter the site's address and notes. Allow device location if you want to test GPS; a typed address works when permission is unavailable.
  5. Continue to Materials & marking. Add separate physical items, including repeated materials. Enter measurements and choose or type a placement.
  6. Capture/upload a photo or choose Use sample. Open Mark image, draw shapes and select Save marked image. Multiple views stay independent.
  7. Review and submit. Close the job, switch to Office view, then open it to verify or request a correction. Editable jobs offer Reassign job.
  8. Use Reports to filter jobs, choose/order columns, add headings and export Excel/CSV. Print / Save PDF uses the browser's print dialog and includes selected visible photos.

Excel and CSV import

Open Recce jobs → Import template to download a genuine Excel workbook. An example is also included in examples/.

Column Use
recce_id Unique job reference. Existing jobs are not overwritten.
shop_name, client_name, site_address Required text fields.
recce_person A manually entered name. No user account is created.
due_date Enter YYYY-MM-DD as text to preserve the intended date.
contact, instructions Optional site contact and work details.

Select Import Excel / CSV, review the rows, then confirm. Only the first Excel worksheet is read. Use a simple .xlsx workbook or CSV UTF-8; old .xls, macros and password-protected workbooks are not supported. Imported jobs start as Assigned. Add photos/materials during the recce.

Photos, marking and reports

Width/height, length and quantities are entered manually. Rectangle area is calculated from those dimensions and quantity, with unit conversion; the app does not determine real-world size from photo pixels. Shape icons include Rectangle, Ellipse, Arrow, Line, Polygon and Draw. Use Select or the mark list to select a mark, then Delete selected; Undo removes the latest mark. To change a shape, remove/redraw it.

Each material supports four photo views. Uploads accept JPEG, PNG or WebP under 10 MB and are compressed to fit local storage. When measurements change, reopen and save the marking to refresh its dimension labels before submitting.

Download a PNG in the marking screen, or download the job's marked-image ZIP, which includes a material index. Excel/CSV contain text fields and a note explaining how to obtain photos; they do not embed image bytes. Use Print/Save PDF for a report with the visible selected image columns. A complete JSON backup includes original compressed photos and saved previews.

Voice, support and device access

Site notes and new support issues can be typed, recorded, or both. Voice recording stores audio, not a transcript. Recordings are limited to 45 seconds / 1 MB. Allow microphone access and stop the recording before leaving or submitting.

Support is a local simulation. Raise an issue, choose Office/Developer and use View / track to reply and change Pending, Processing or Resolved. You can demonstrate escalation from Office to Developer. Nothing is sent to an actual team, developer or WhatsApp number. Office/Recce view is a presentation switch, not an authentication or permissions system.

Camera access depends on the device/browser; some desktop devices show a file picker. Physical mobile microphone/camera/GPS testing generally requires a trusted HTTPS-hosted copy. A computer's localhost address will not open that computer's files on a phone. This package has not been publicly deployed.

Keep or reset your changes

Changes save only in this browser's local storage. They do not synchronise with another device, the production project or another person's browser. Private browsing or clearing browser data may remove them. Large numbers of photos/audio can reach the storage quota.

Use Save demo backup before closing or moving devices. To restore or reset, use the ? button in the top bar. Restore accepts this demo's JSON format; it replaces the local dataset after confirmation. Treat a backup containing your own photos or voice as a private file.

This is a prototype for exploring a workflow. Multi-user collaboration, protected data storage, real support delivery, production approvals/audit guarantees and offline synchronisation belong to the full application and are not provided by this standalone demo.
